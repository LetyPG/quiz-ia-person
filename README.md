# Quiz: AI or Human? 🤖👤

Lightweight, interactive, and portable web application to evaluate the ability to discern between responses generated by Artificial Intelligence and those written by a Human. This app is a representation of Turing test. This quiz was created for a talk at Agile UY 2026.

---

## Key Features

- **Welcome Screen (`index.html`)**: Introduction with quick instructions, 90s timer indicator, placeholder for logo, and start button.
- **Interactive Quiz (`quiz-page.html`)**: 10 single-choice questions with a 90-second countdown timer.
- **Instant Evaluation**:
  - Each correct answer is worth 10 points, a 70% for success, if no answer selected it is counted as incorrect, this means *0 points*
  - Score percentage calculation (`%`).
  - Conditional message: 
    - **🎉 ¡Felicitaciones, lograste identificar a la IA! 🎉** for scores above 70%.
    - **😢 Lo siento, fuiste engañado por la IA 😢** for scores below 70%.
  - Detailed breakdown with numbers of correct (green) and incorrect (red) questions.
  - Option to restart the test.
- **Responsive Design**: Color palette in blue (`#003366`) and yellow (`#fff9db`, `#ffd43b`) tones.
- **Zero external dependencies**: Built 100% with native HTML5, CSS3, and JavaScript.

## 1. Checking Dependencies on the Target Machine

Before running the local server, you can check which tools you have installed by running the following commands in your terminal:

### To check Python:
```bash
python3 --version
# or on Windows:
python --version
```
*If it returns something like `Python 3.x.x`, you can already use Python.*

### To check Node.js / NPM:
```bash
node -v
npx -v
```
*If it returns versions like `v18.x.x` or higher, you can use `npx serve`.*

### To check PHP:
```bash
php -v
```

## 2. Installation / Downloading Dependencies (if not installed)

If your machine does not have any of the options above, you can install the one you prefer (**Python 3** is recommended for its lightweight nature):

### Install Python 3

- **Ubuntu / Debian / Linux Mint**:
  ```bash
  sudo apt update && sudo apt install -y python3
  ```
- **Fedora / Red Hat / CentOS**:
  ```bash
  sudo dnf install -y python3
  ```
- **Arch Linux / Manjaro**:
  ```bash
  sudo pacman -Sy python
  ```
- **macOS** (via Homebrew):
  ```bash
  brew install python
  ```
- **Windows**:
  - Via terminal (PowerShell / CMD with Winget):
    ```powershell
    winget install Python.Python.3.12
    ```
  - Or by downloading the official installer from [python.org/downloads](https://www.python.org/downloads/) *(check the box "Add python.exe to PATH")*.

---

## 3. Execution and Deployment Instructions

### Option A: With Python 3 (Recommended)
```bash
# 1. Navigate to the project folder
cd quiz

# 2. Start the server on port 8000
python3 -m http.server 8000
# On Windows: python -m http.server 8000

# 3. Open in browser
http://localhost:8000
```

### Option B: With Node.js (`npx serve`)
```bash
cd quiz
npx serve .
```

### Option C: With PHP
```bash
cd quiz
php -S localhost:8000
```

### Option D: With the "Live Server" Extension in VS Code
1. Open the `quiz` folder in VS Code.
2. Right-click on `index.html` and select **"Open with Live Server"**.

### Option E: Offline Mode (Directly in Browser, Without Server)
Being an application based on pure static files, you can also open `index.html` directly:
- **Linux**: `xdg-open index.html`
- **macOS**: `open index.html`
- **Windows**: `start index.html`

## 4. Customization

### 1. Change the Logo
Place your image file (e.g. `logo.png`) in the root of the project and edit `index.html`:
```html
<div class="logo-container" id="logo-placeholder">
    <img src="logo.png" alt="Logotipo">
</div>
```

### 2. Modify Questions or Time
In [app.js](./app.js):
- **Questions**: Edit the `questionsData` array.
- **Time limit**: Modify the constant `const TOTAL_TIME = 60;` (in seconds).
